This project was completed in collaboration with UNP to analyze engineering graduate characteristics and classify expected salaries into Low and High Salary categories using Machine Learning. The dataset of 2,998 graduates was analyzed based on academic performance, aptitude scores, engineering specialization, college GPA, college tier, and technical skills. Using Python, the data was preprocessed, relevant features were selected, and salary categories were created based on the median salary. The analysis also explored salary distribution, degree types, college factors, aptitude scores, and gender differences. Logistic Regression, Decision Tree, and Random Forest models were developed and evaluated using accuracy, precision, recall, and F1-score across different train-test splits. Logistic Regression achieved a maximum accuracy of 0.72, while Random Forest showed the best overall performance. The project demonstrates how classification techniques can identify salary patterns and support data-driven salary assessment and recruitment decisions.
